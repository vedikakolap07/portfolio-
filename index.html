AI calling automation that a business analyst can run alone

Anvex Speak places outbound AI voice calls for business campaigns. I built its voice bots on Vapi, introduced n8n to the team, and designed the whole flow so analysts could set up, test and report on a campaign without waiting for a developer.

01 I built the voice bots

Configured the Vapi agents for each campaign, with dynamic variables that pull in customer and campaign data so every call sounds specific.

02 I introduced n8n

Proposed n8n to the team and set it up as the layer that connects Vapi, PBX/SIP and our Node.js APIs, so agent setup and SIP provisioning run automatically.

03 I made it easy for analysts

Designed the workflow and a Demo Call module so a business analyst can configure an agent, test a call and launch a campaign on their own.

04 I automated the reports

Call status, recordings and analytics are fetched automatically after each run and turned into reports, instead of someone pulling them by hand.

20+ clients ran AI-driven outreach campaigns on this setup.
